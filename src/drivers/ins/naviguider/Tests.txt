Parameter Behavior Test Cases

Pertinent Parameters:
    > EKF2_EN:      Enables/disables the EKF2
    > SENS_EN_NG:   Enables the NaviGuider
    > SENS_NG_MODE: Sets the NaviGuider to sensors only (0) or INS (1) mode

Pertinent Actions:
    > Flashing the firmware.
    > Resetting all parameters to defaults via QGC.
    > (Re)Setting EKF2_EN
    > (Re)Setting SENS_EN_NG
    > (Re)Setting SENS_NG_MODE

Known Behaviors:
    > Setting SENS_NG_MODE will reset EKF2_EN once the NaviGuider driver runs.
    > Resetting SENS_NG_MODE will set EKF2_EN once the NaviGuider driver runs.
    > In ROMFS/px4fmu_common/init.d/rcS it starts ekf2 if EKF2_EN is set.
    > In ROMFS/px4fmu_common/init.d/rcS it runs rc.sensors before checking EKF2_EN.
    > In ROMFS/px4fmu_common/init.d/rc.sensors it starts naviguider if SENS_EN_NG is set.

Suspected Behaviors:
    > Flashing the firmware does not always set parameters to their defaults.
    > Resetting the EKF2_EN manually does not stop the EKF system.
    > Setting SENS_NG_MODE does not always prevent the EKF system from starting.

Desired Behaviors:
    > NaviGuider only publishes to vehicle_attitude is EKF2 is not running.
