# برنامج نظام الطيار الآلي PX4

يُعد **PX4** برنامجاً مفتوح المصدر للتحكم في أنظمة الطيران (Flight Control Software)، صُمم خصيصاً للطائرات المسيرة (Drones) والمركبات المستقلة غير المأهولة (Unmanned Vehicles).

يوفر هذا المشروع بيئة مرنة ومتكاملة من الأدوات لمطوري أنظمة الطيران المسير، مما يتيح لهم مشاركة التقنيات المتقدمة وبناء حلول هندسية مخصصة لتطبيقات الطيران المختلفة.

---
> **ملاحظة:** هذا الملف هو ترجمة رسمية للتوثيق الأساسي، يهدف إلى دعم المهندسين والمطورين في المجتمع التقني العربي للوصول إلى تقنيات PX4.
